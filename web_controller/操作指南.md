# Web 控制器操作指南

本指南是 `web_controller/README.md` 的精简操作版。安装、接口和配置细节已合并到 `web_controller/README.md`，这里保留日常实验流程。

## 1. 启动

```bash
cd /Users/venele/Downloads/fault-injection
. .venv/bin/activate
./start_frontend.sh
```

访问 `http://<宿主机IP>:8080`。如果只想启动 Web 服务：

```bash
uvicorn web_controller.app:app --host 0.0.0.0 --port 8080
```

## 2. 进入页面后先做三件事

1. 点“刷新配置”，确认 master、slave1、slave2 节点已加载。
2. 点“K8s / Chaos 状态查看”，确认 Kubernetes 与 Chaos Mesh CRD 可访问。
3. 点“查看状态”，确认命令输出区域能正常返回。

## 3. Chaos Mesh 实验

推荐顺序：

1. “部署演示应用”，默认创建 `default/nginx-demo`。
2. 执行一个 Chaos 实验：
   - Pod Kill
   - Container Kill
   - 网络延迟
   - 网络丢包
   - CPU 压力
   - 内存压力
3. 点“查看混沌实验”，观察 `PodChaos`、`NetworkChaos`、`StressChaos` 与事件。
4. 点“清理混沌实验”，按类型或全部清理。

当前功能测试页面中的 K8s 用例会自动执行 baseline、注入、验证和 cleanup，适合演示。

## 4. Hadoop 操作

Hadoop 动作仍保留在 Web 单次动作中：

- 节点进程状态：对所有节点执行 `jps`
- 启动、停止、重启 Hadoop
- 进程故障：`crash`、`hang`、`resume`
- 网络故障：延迟、丢包、乱序、隔离、心跳超时
- 资源故障：CPU、内存、磁盘填充、I/O 限速
- HDFS/YARN：安全模式、磁盘不足、YARN 不健康
- MapReduce：杀死 Map 或 Reduce 任务

Hadoop 注入器路径由 `web_controller/config.json` 的 `hadoop.injector` 决定，当前配置要求 master 节点上存在 `/root/hadoop-fi/hadoop_injector`。

## 5. VM 与 KVM 操作

VM 动作在宿主机本地执行：

- `process_injector`：进程崩溃、挂起、恢复
- `network_injector`：延迟、丢包、端口隔离、报文损坏、清理
- `cpu_injector`：CPU 压力
- `mem_leak`：内存占用
- `mem_injector`：ptrace 内存篡改
- `reg_injector`：ARM64 寄存器注入

KVM 动作通过 `vm_injection/kvm_injector` 执行：

- 虚拟机列表
- 软错误：`soft-flip`、`soft-swap`、`soft-zero`
- 客户机异常：`guest-data`、`guest-divzero`、`guest-invalid`
- 性能故障：`perf-delay`、`perf-stress`、`perf-clear`
- CPU 热插拔：`cpu-offline`、`cpu-online`
- 一键清理：`clear`

## 6. CloudStack 操作

Web 中保留 CloudStack 服务状态、组件进程、API 延迟和网络隔离动作。直接使用 CLI 时以 `kvm_injection/cloudstack-fi/cloudstack_injector.c` 为准：

```bash
sudo ./cloudstack_injector list
sudo ./cloudstack_injector hang agent
sudo ./cloudstack_injector resume agent
sudo ./cloudstack_injector api-delay 1000
sudo ./cloudstack_injector api-delay-clear
sudo ./cloudstack_injector network 192.168.1.11 8250
sudo ./cloudstack_injector network-clear 192.168.1.11
```

## 7. 常见问题

| 现象 | 检查点 |
| --- | --- |
| 页面无输出 | 检查后端是否运行在 8080，浏览器网络请求是否失败 |
| SSH 失败 | 检查 `config.json` 中用户、私钥、端口和节点 `local` 设置 |
| sudo 失败 | 配置免密 sudo，或用 root 启动控制器 |
| Chaos 资源查询失败 | 确认 Chaos Mesh 已安装，`kubectl get podchaos,networkchaos,stresschaos -A` 可执行 |
| Hadoop 注入失败 | 确认 master 上的 `hadoop_injector` 路径和 slave 免密 SSH |
| VM/KVM 注入失败 | 确认 `vm_injection/` 已 `make all`，相关二进制可执行 |
